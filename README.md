# AtomQuest — Goal Tracking Portal

AtomQuest is a modern Goal Tracking and Performance Management Portal built using React, HTML, CSS, and JavaScript.

It supports Employees, Managers, and Admins with features such as:

- Goal Creation & Tracking
- Goal Approval Workflow
- Quarterly Check-ins
- Progress Monitoring
- Shared Goals
- Reports & CSV Export
- Audit Logging
- Role-based Access

---

# Features

## Employee Features
- Create and edit goals
- Assign weightages
- Submit goals for approval
- Perform quarterly check-ins
- Track progress scores

## Manager Features
- Approve or reject employee goals
- Push shared goals to team members
- View team performance reports

## Admin Features
- Monitor organization-wide goals
- Unlock approved goals
- Access audit logs
- Generate reports
